## 📖 Project Overviews & What Was Done

### 1. Byte the Forager (Browser Game)
**What I Built:**
* **Interactive Web Game:** Developed a complete, browser-playable 2D foraging game built from scratch using HTML5, CSS3, and JavaScript, packaged into a single deployable file (`index.html`) and hosted live via GitHub Pages.
* **Gameplay & Mechanics:** Implemented real-time player movement, item collection ("bytes"), obstacle/hazard avoidance, collision detection, and a live scoring system.
* **Documentation & User Guides:** Authored a comprehensive **How-to-Play Manual** explaining controls, rules, and objectives, alongside a **Project Report** covering the game's architecture, design logic, and development workflow.

**Related Files:**
* `index.html` — Core game source code and playable web interface[cite: 4].
* `Byte_the_Forager_How_to_Play (1).pdf` — Player guide covering rules, controls, and scoring[cite: 4].
* `Byte_the_Forager_Report.pdf` — Technical report detailing the game's design and implementation[cite: 4].

### 2. Online Shopping Purchase Intention Detector (Data Science)
**What I Built:**
* **Exploratory Data Analysis (EDA):** Analyzed the `online_shoppers_intention.csv` dataset to uncover behavioral patterns across user sessions—examining metrics like administrative/product page views, duration spent on pages, bounce rates, exit rates, and visitor types.
* **Data Preprocessing & Feature Engineering:** Cleaned the dataset, handled categorical features (such as month, operating system, browser, and visitor type), and scaled numerical features to prepare the data for predictive modeling.
* **Machine Learning Classification:** Built, trained, and evaluated classification models in Python to detect whether an online shopping session will result in a completed purchase (`Revenue`).
* **Insights & Reporting:** Summarized key behavioral drivers of e-commerce conversions and documented model evaluation metrics (accuracy, precision, recall, F1-score) in a final project report.

* `idse project.ipynb` — End-to-end Jupyter Notebook containing data cleaning, visualizations, model training, and evaluation[cite: 4].
